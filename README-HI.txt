अम्बे गोविन्द स्टील फर्नीचर — पूरी प्रोफाइल वेबसाइट

1) इस ZIP को extract करके सभी फाइलें GitHub repository के root में upload करें।
2) assets/js/main.js खोलें और YOUR_GITHUB_USERNAME तथा YOUR_REPOSITORY_NAME बदलें।
3) Repository public रखें ताकि GitHub Contents API फोटो पढ़ सके।
4) assets/images/products/ के अंदर category folder बनाएं (जैसे almirah, rack, bed) और उसमें फोटो डालें। नया folder बनाते ही category अपने-आप वेबसाइट पर दिखेगी।
5) sitemap.xml और robots.txt में YOUR-WEBSITE-DOMAIN को वास्तविक custom domain से बदलें।
6) Instagram QR image और @mbanaujara लिंक शामिल है। यदि QR scan करने पर कोई दूसरा Instagram account खुले तो बताएं, लिंक ठीक कर देंगे।
7) Shop board और Instagram QR की images assets/images/ में रखी गई हैं।
8) फोन नंबर/पता दुकान के बोर्ड से लिए गए हैं।
